## What it actually does

Given a user message, it extracts an index symbol by keyword (defaults
to `NIFTY` — the project's own initial market priority — when no index
is named), calls both allowed tools, and synthesizes a plain-text answer
by templating the real tool output. "Synthesize" is deterministic string
formatting, not natural-language generation — there is no working model
yet (Stage C's `OwnGenAiProvider` is still a skeleton) to generate prose
with. A failed tool call is reported in the answer as "unavailable:
\<reason\>", never silently dropped or replaced with invented numbers.

Live at `GET /api/v1/agents`, `GET /api/v1/agents/{id}`,
`GET /api/v1/agents/{id}/health` (Section 14.3).
